# SideStore Anisette Server List

Self-hosted anisette-v3 server on Koyeb, used by SideStore.

Server list URL:

    https://hanoch799.github.io/sidestore-anisette/servers.json

In SideStore: Settings -> scroll to bottom -> Anisette Servers -> paste the URL above -> Refresh Servers -> select `zaiyongde-koyeb`.
